Pulsed Media Google Drive Transfer

This is a personal setup that uses rclone, an open-source file transfer tool, to upload selected files from my Pulsed Media seedbox to my own Google Drive account.

The purpose is to store completed downloads in Google Drive so I can access my files from my other devices.

This is a personal-use configuration, not a public file hosting service. Files are transferred only for my own use.
